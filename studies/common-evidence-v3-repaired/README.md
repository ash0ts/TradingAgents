# Shared evidence, with and without required citations

This separately frozen **development** study repairs the stopped pilot's
ambiguous citation instruction. Provenance hashes belong to harness metadata;
actors supply fact references and a constrained list of unavailable sources.
The original 40 pilot executions remain in `../common-evidence-v3/pilot-results.json`.
Their $1.247739 cost, including qualification, counts against this work's combined
$30 sub-cap and the original $250 ledger. They are excluded from the complete
campaign's financial summaries because the stopped schedule is unbalanced.

Both new arms receive the exact same compact stock/SPY, SEC and FRED brief in
every role. Tools cannot recover hidden raw history. Old filing periods and
missing news/social/event calendars are explicit. A deterministic receipt
separates stock principal, entry fees and remaining cash. The cited arm alone
adds exact reference fields, explicit missing-source fields, and an execution
gate. An exact reference can still fail to support a narrative inference.

`protocol.json` fixes the case grid, feature/source hashes, models, cost-only
design selection, randomized arm ordering, review selection, scoring and stop
rules before qualification. All five cohorts and three systems are retained.
The original November 5, 2026 evidence/outcome freeze remains in force. This is
not an untouched test, news-response experiment, or demonstration of alpha.

```sh
python scripts/run_repaired_evidence_campaign.py qualify
python scripts/run_repaired_evidence_campaign.py select
python scripts/run_repaired_evidence_campaign.py run
python scripts/audit_evidence_campaign.py
python scripts/export_evidence_campaign.py
```

The original and contract-only campaigns remain unchanged. A four-version table
keeps each earlier trial and its source conversation visible. The new portfolio
comparison includes SPY at each decision's exact invested fraction, with matching
fees and timing. Matching capital does not match beta or volatility.

Public exports are allowlisted derived data; raw prices, reports and detailed
briefs remain in the private evidence project. Agent Lens conversation links
require team access. Read `verification.json`, the selected assistant reviews,
and publication receipts before treating an execution as a demonstrated result.
